# 产业园地下车库照明灯组分区批量划转管理系统

## 项目简介

本系统用于园区物业管理地下车库照明灯组，支持照明灯组建档、单组或批量分区划转、批量操作台账、分区资产导出，以及灯组巡检异常处置（巡检批次、现场快照、复核退回/确认、处理收口、并发受控与全程可追溯）。

## 灯组巡检异常处置模块

从首页左侧「灯组巡检」「异常处置」进入，覆盖完整闭环：

1. **创建巡检批次**：选择一个或多个分区，系统按巡检开始时点快照分区内灯组（编号、安装位置、所属分区）。
2. **逐个登记 / 暂存补录**：每个灯组记录「正常 / 熄灭 / 频闪 / 亮度不足」四种结果；异常必须填写现场说明；可随时暂存后继续补录。
3. **提交批次**：全部登记后提交，自动形成异常清单（灯组编号、所属分区、异常类型、说明、上报人、上报时间），提交后原始巡检结果固化、不能被覆盖。
4. **分区划转快照**：若灯组在巡检后被划转，异常清单仍保留巡检时分区快照，并实时标出「当前已划转」与当前分区。
5. **受控复核处置**：复核人可「确认异常」（必填处理意见、处理时限）或「退回补充」；被退回项补充后重新进入待复核；确认后登记处理结果并关闭，关闭为终态、只读不可改回。
6. **可追溯历史**：每次上报、退回、补充、确认、登记处理结果、关闭都记录时间、操作人、内容，形成连续处置时间线。
7. **并发冲突控制**：异常处置基于「状态 + 乐观锁版本号」原子条件更新；两名复核人同时提交同一条待复核异常时，仅第一个生效，后提交者收到 409 冲突提示并看到最新内容，不会覆盖结论或重复生成处理记录。

后端关键接口位于 `/api/inspection/**`，集成测试见 `backend/src/test`（含全流程、分区划转快照、并发复核 HTTP 用例）。

## 技术栈

- 前端：Vue 3、Vite、Element Plus
- 后端：Spring Boot 3.1、JDK 17、MyBatis Plus、Redis
- 数据库：MySQL 8.0
- 部署：Docker Compose

## 端口说明

## Docker 构建说明

Docker Compose 使用固定端口并绑定 `127.0.0.1`；前端容器内部端口为 8117，外部访问端口由 `.env` 的 `FRONTEND_PORT=8232` 提供。

## 常见问题

- 后端编译失败时先执行 `mvn -version` 检查 JDK，再检查 Lombok、Maven 编译插件和 `pom.xml` 是否被忽略。
- 前端构建失败时优先按实际报错检查 import 路径、导出名、Vite 代理端口和构建期语法。
- 页面中文乱码时检查源码、SQL 初始化脚本、数据库字符集、连接串编码和已有 Docker volume 数据；初始化 SQL 已增加 `SET NAMES utf8mb4;`。
